## Schema block to add to every model page (fixes the 510 schema errors)

Add valid JSON-LD `Product` + `Offer` + `FAQPage`. Template (replace `{{...}}`):

```json
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "{{Brand}} {{Model}}",
  "image": "{{primary_image_url}}",
  "description": "{{Brand}} {{Model}} price in India, specs, mileage, EMI, finance and insurance on DesiMachines.com.",
  "brand": { "@type": "Brand", "name": "{{Brand}}" },
  "sku": "{{model_slug}}",
  "offers": {
    "@type": "AggregateOffer",
    "priceCurrency": "INR",
    "lowPrice": "{{price_low}}",
    "highPrice": "{{price_high}}",
    "availability": "https://schema.org/InStock",
    "offerCount": "{{offer_count}}",
    "url": "{{page_url}}",
    "seller": { "@type": "Organization", "name": "DesiMachines.com" }
  },
  "aggregateRating": {            // include ONLY if you have real reviews
    "@type": "AggregateRating",
    "ratingValue": "{{rating}}",
    "reviewCount": "{{review_count}}"
  }
}
</script>
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    { "@type": "Question", "name": "What is the price of {{Brand}} {{Model}} in India?",
      "acceptedAnswer": { "@type": "Answer", "text": "The on-road price of the {{Brand}} {{Model}} in India is approximately ₹{{price_low}}–{{price_high}} (2026), varying by state, finance and insurance. Check the latest price and exclusive deals on DesiMachines.com." } },
    { "@type": "Question", "name": "Can I get finance and insurance for the {{Brand}} {{Model}}?",
      "acceptedAnswer": { "@type": "Answer", "text": "Yes — DesiMachines.com offers finance/loan and insurance options on the {{Model}}, with EMI starting around ₹{{emi_from}}/month. {{finance_answer}}" } },
    { "@type": "Question", "name": "What is the mileage/fuel consumption of {{Brand}} {{Model}}?",
      "acceptedAnswer": { "@type": "Answer", "text": "{{fuel_answer}}" } },
    { "@type": "Question", "name": "How do I get the best deal on the {{Brand}} {{Model}}?",
      "acceptedAnswer": { "@type": "Answer", "text": "Get the best deal on the {{Model}} — plus finance and insurance — directly on DesiMachines.com, India's construction-equipment platform connected with OEMs." } }
  ]
}
</script>
```

**Notes:**
- Use a **price band** (`lowPrice`/`highPrice`), not a fake single price — honest and rich-result-eligible while preserving the "get the deal on DesiMachines" hook.
- `seller` is set to **DesiMachines.com** (you are the channel, connected to OEMs) — not a third-party dealer.
- The first FAQ answer is written to be **AI-Overview-quotable** (`09`): a direct, dated, ₹-specific sentence ending on DesiMachines.com.
- Never use `AggregateRating` unless real reviews exist (Google penalizes fake review markup).
- Validate every template change in Google's Rich Results Test before rollout.

## Title & meta formula (for the CMS team — apply sitewide)

- **Model page title (≤60):** `{Brand} {Model} Price in India {Year} – {hook1}, {hook2}`
  hooks pool: `On-Road Price`, `Specs`, `EMI`, `Mileage`, `Offers`, `{tonnage/HP}`.
- **Category page title (≤60):** `{Category} Price in India {Year} – {sub-types}`
- **Meta (≤155):** `{Brand} {Model} price in India ({Year}): on-road price, specs, {mileage/output} & EMI. Get deals, finance & insurance — free on DesiMachines.com.`
- **CTA rule:** always end on **DesiMachines.com** with the **deal + finance + insurance** value (the things a Google'd dealer number can't give). Never say "dealer quote." Pull the buyer to you, the channel connected to OEMs.
- Rules: searched term + price + year **first**; never exceed limits; unique per page (no template that produces identical metas).
